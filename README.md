# Sentiment Analysis using Python

## 📌 Project Overview
This project analyzes text and identifies its sentiment as **positive, negative, or neutral** using sentiment analysis techniques.

## 🚀 Features
- Analyzes text input to determine sentiment.
- Classifies text based on its emotional tone.
- Uses Python for implementation.

## 🛠️ Technologies Used
- Python
- Sentiment Analysis / NLP
- Required Python libraries listed in `Req.txt`

## 📂 Project Structure
```text
Sentiment-Analysis/
├── Agent.py
├── Req.txt
└── README.md
```

## ⚙️ Installation and Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/VenkataPrasanna25/Sentiment-Analysis.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Sentiment-Analysis
   ```

3. Install the required dependencies:
   ```bash
   pip install -r Req.txt
   ```

## ▶️ How to Run
Run the Python file:
```bash
python Agent.py
```

Follow the instructions displayed by the program.
